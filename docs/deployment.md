# Local and pilot deployment

Local: install `requirements-local.txt`, copy `.env.example` to `.env`, set a long random `ADMIN_TOKEN`, train the baseline checkpoint with `python train_baseline.py`, run `alembic upgrade head`, then start with `python -m app.app`. Keep debug disabled outside local development. The app defaults to SQLite at `app/instance/grieveai.db` if `DATABASE_URL` is unset or blank. Alembic owns schema changes; startup does not call `create_all`.

For PostgreSQL, set a PostgreSQL SQLAlchemy URL in `DATABASE_URL`, install its driver, and run `alembic upgrade head` before app startup; no application-code switch is needed. PostgreSQL is not installed/tested in the current environment. Set `SECRET_KEY`, `ADMIN_TOKEN`, `DATABASE_URL`, `CONFIDENCE_THRESHOLD`, `DEDUPE_THRESHOLD`, `MODEL_BACKEND`, `MURIL_CHECKPOINT_DIR`, `TAXONOMY_CONFIG`, `DEPARTMENTS_CONFIG`, `SLA_CONFIG`, and optional provider endpoint/model/key settings through environment variables. Do not commit `.env`, credentials, real records, or generated institutional exports. Place the service behind HTTPS and institutional authentication before a real pilot; the shared-token admin mechanism is a demo control, not a complete institutional identity solution.
