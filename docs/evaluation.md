# Evaluation protocol

`train_baseline.py` trains the local TF-IDF + Logistic Regression/Ridge baseline on the duplicate-safe 60% split, calibrates the confidence gate on validation data, and reports validation and held-out test results. `train_baselines.py` compares keyword rules with TF-IDF + Linear SVM. `src/train.py` trains the available MuRIL + LoRA path. Current synthetic outputs are pipeline checks, not VCET pilot results.

Report category and subcategory Macro-F1, high-priority recall (priority ≥ 4), and priority MAE. Routing accuracy requires a validated gold department column. The live app's override-rate denominator is automatically routed tickets (manual-review tickets are excluded); the numerator is distinct automatically routed tickets with at least one recorded route override. Both must remain unavailable when their evidence/denominator is absent. Also collect summary factuality ratings and submission/prediction/routing timestamps before reporting factuality or time-to-route results.

`make_splits()` groups both duplicate references and exact normalized-text copies before producing deterministic train/validation/test partitions. `ML_CONFIDENCE_THRESHOLD` (or the backwards-compatible `CONFIDENCE_THRESHOLD`) overrides the validation-calibrated threshold. Training reports high-priority recall using the rounded priority value the application returns and reports raw-score-cutoff recall separately. See [priority analysis](priority_analysis.md). Never present synthetic scores as VCET evidence.
