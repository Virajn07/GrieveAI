# Evaluation protocol

The primary Flask model is the supplied IndicBERT v2 + LoRA Run 1 adapter. Its archived metrics are category Macro-F1 1.000, subcategory Macro-F1 0.9122, and priority MAE 0.5395 on the synthetic experiment only. The adapter's original base-model revision was not recorded. `train_baseline.py` separately trains the TF-IDF + Logistic Regression/Ridge baseline on duplicate-safe splits; `train_baselines.py` compares keyword rules with TF-IDF + Linear SVM; `src/train.py` retains the secondary MuRIL + LoRA path. Synthetic results are not VCET pilot results.

The presentation-ready report at [PRESENTATION_METRICS.md](PRESENTATION_METRICS.md) distinguishes validation from held-out test results, current same-split baselines from older incompatible experiments, and archived from locally reproduced metrics. Use it as the canonical source for presentation figures.

Report category and subcategory Macro-F1, high-priority recall (priority ≥ 4), and priority MAE. Routing accuracy requires a validated gold department column. The live app's override-rate denominator is automatically routed tickets (manual-review tickets are excluded); the numerator is distinct automatically routed tickets with at least one recorded route override. Both must remain unavailable when their evidence/denominator is absent. Also collect summary factuality ratings and submission/prediction/routing timestamps before reporting factuality or time-to-route results.

`make_splits()` groups both duplicate references and exact normalized-text copies before producing deterministic train/validation/test partitions. `ML_CONFIDENCE_THRESHOLD` (or the backwards-compatible `CONFIDENCE_THRESHOLD`) overrides the configurable review gate. The default 0.70 is a demo setting and is not a validated optimum. Training reports high-priority recall using the rounded priority value the application returns and reports raw-score-cutoff recall separately. See [priority analysis](priority_analysis.md). Never present synthetic scores as VCET evidence.
