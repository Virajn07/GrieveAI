# VCET pilot preparation

Before a pilot, obtain institutional approval and a privacy/de-identification protocol. Have annotators agree the seven-category taxonomy, subcategories, department mappings, priority rules, statuses and SLA values; none of the current demo values are official VCET policy. Record label provenance and resolve disagreement before freezing train/validation/test data.

Keep test records and duplicate groups out of training. Tune the confidence threshold on validation data only. Use a small reviewed pilot to assess incorrect routing, missed urgent cases, privacy failures, overrides, summary factuality and operational latency. Define a rollback/contact process before exposing the service to students. This repository does not claim that a VCET pilot has happened.
